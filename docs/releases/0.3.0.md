## TrustedServer v0.3.0

本版本继续提供以下 Fabric 构建：

- Minecraft 1.20.1
- Minecraft 1.20.2
- Minecraft 1.20.4
- Minecraft 1.21.1

### 主要更新

- 接通可选整连接安全隧道：离线模式新增 AES-256-GCM 传输层，正版模式替换原版 AES-CFB8；支持 `disabled`、`optional`、`required`。
- 新增客户端 `config/trustedserver/client.json`，可用 `wantTunnel` 请求 optional 隧道。
- 完善认证密钥导出与导入界面，明文导出改为显式风险确认复选框。
- 增加 Minecraft 标准 i18n 支持，内置简体中文、繁体中文、日语和英语。
- `/passwd` 与 `/recoverypasswd` 注册为本地客户端命令，支持命令名自动补全。
- 密码命令不会进入原版服务端命令包或聊天历史，异常日志也不会记录完整命令。

### 安装与升级

客户端和服务端必须安装与 Minecraft 版本对应的同版本 jar。建议客户端与服务端同时升级；升级前请备份 `config/trustedserver/`。

高安全隧道默认不会由客户端主动请求。需要 optional 模式时，将客户端 `config/trustedserver/client.json` 中的 `wantTunnel` 设置为 `true`。

`SHA256SUMS.txt` 包含本次四个发布 jar 的 SHA-256 校验值。
